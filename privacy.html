Política de privacidad

Última actualización: 25 de septiembre de 2026

Borrador para revisión. Antes de publicar esta política, el responsable del proyecto debe confirmar su identidad y datos de contacto, las jurisdicciones aplicables, las prácticas de conservación y eliminación, y los servicios externos efectivamente utilizados. Este texto es informativo y no constituye asesoría legal.

Esta política describe, en términos generales, cómo la aplicación de escritorio Jarvis (“Jarvis” o “la aplicación”) puede tratar información cuando la utilizas. Jarvis es un proyecto independiente para Windows. Algunas funciones dependen de servicios externos que tú configuras.

Información y almacenamiento local

Jarvis puede procesar lo que escribes o dices, notas, recordatorios, preferencias y comandos para ejecutar las funciones que solicites. Las notas se guardan en una base de datos local. La aplicación puede mantener historial de conversación y otros datos de configuración en archivos del equipo. Revisa y protege tu dispositivo; quien tenga acceso a esos archivos podría acceder a su contenido.

Micrófono, pantalla y cámara

El uso del micrófono permite detectar comandos y transcribir voz. Algunas funciones de voz pueden enviar audio a un proveedor de transcripción configurado. El análisis de pantalla puede compartir una captura con el modelo de IA elegido; la lectura OCR está diseñada para procesarse localmente. Las funciones de gestos usan la cámara cuando las activas. La aplicación indica que las capturas de pantalla de análisis son efímeras y no se guardan en disco. Comprueba en la configuración de tu versión qué permisos y proveedores están habilitados.

Proveedores externos

Según tu configuración, Jarvis puede enviar texto, consultas, audio u otra información necesaria a proveedores de modelos de IA, transcripción, síntesis de voz, búsqueda web, noticias, mapas, imágenes o servicios de Google. Cada proveedor procesa los datos bajo sus propias políticas y condiciones. Consulta sus documentos antes de conectar una cuenta o introducir información sensible. La disponibilidad depende de las claves y opciones que configures.

Google y otras cuentas

Si autorizas integraciones de Google, Jarvis accede a los datos y acciones que cubren los permisos OAuth concedidos, que pueden incluir Gmail, Calendar, Tasks, Contacts y Drive. Revoca el acceso desde la configuración de seguridad de tu cuenta de Google cuando ya no lo necesites. No compartas tokens ni archivos de credenciales.

Finalidades y control

La información se utiliza para responder a tus solicitudes, ejecutar acciones, guardar los elementos que creas, mantener preferencias y resolver errores. Puedes desactivar integraciones, retirar permisos de Windows o Google y eliminar datos locales desde la aplicación o borrando los archivos asociados, teniendo en cuenta que esto puede impedir el funcionamiento o borrar contenido que desees conservar.

Seguridad y menores

Protege las claves API, credenciales y datos almacenados en tu equipo. No introduzcas información confidencial salvo que comprendas el flujo hacia servicios de terceros. Jarvis no está diseñado como servicio para menores ni como herramienta médica o de emergencia.

Cambios y contacto

Esta política puede actualizarse al cambiar la aplicación o sus integraciones. El responsable debe completar y publicar aquí un canal de contacto verificable para preguntas o solicitudes relacionadas con privacidad antes de ofrecer el producto públicamente.
