## 1) Sistema y control del PC

Estas acciones controlan la máquina y sus programas:
- abrir_app
- cerrar_app
- minimizar_app
- maximizar_app
- poner_volumen
- subir_volumen
- bajar_volumen
- mute
- subir_brillo
- bajar_brillo
- poner_brillo
- apagar
- reiniciar
- bloquear
- suspender
- hibernar
- modo
- buscar_archivo
- aprender_app

### Qué hace cada una
- abrir_app: abre una aplicación
- cerrar_app: cierra una app
- minimizar_app: minimiza una ventana
- maximizar_app: maximiza una ventana
- poner_volumen: ajusta volumen al valor indicado
- subir_volumen: sube volumen
- bajar_volumen: baja volumen
- mute: silencia
- subir_brillo: sube brillo
- bajar_brillo: baja brillo
- poner_brillo: fija brillo
- apagar: apaga PC
- reiniciar: reinicia PC
- bloquear: bloquea sesión
- suspender: suspende el equipo
- hibernar: hiberna el equipo
- modo: activa un modo predefinido
- buscar_archivo: busca un fichero o carpeta
- aprender_app: aprende una aplicación para reconocerla mejor después

### Requiere
- Windows
- permisos de sistema
- apps instaladas
- interacción con archivos locales

### Ejemplos
- “abre Spotify”
- “sube el volumen”
- “baja el brillo”
- “reinicia el equipo”
- “modo estudio”

## 2) Pantalla, ratón, teclado y gestos

Estas acciones manejan la interacción con lo que vemos:
- ver_pantalla
- analizar_pantalla
- leer_pantalla
- activar_gestos
- desactivar_gestos
- calibrar_gestos
- recalibrar_gestos
- hacer_click
- escribir
- pulsar_tecla
- desplazarse
- hacer_zoom

### Qué hace cada una
- ver_pantalla: visualiza la pantalla
- analizar_pantalla: interpreta el contenido visible
- leer_pantalla: extrae texto de la pantalla
- activar_gestos: activa control por gestos
- desactivar_gestos: desactiva control por gestos
- calibrar_gestos: calibra gestos
- recalibrar_gestos: vuelve a calibrar
- hacer_click: hace click
- escribir: escribe un texto
- pulsar_tecla: pulsa tecla o combinación
- desplazarse: mueve el cursor o el scroll
- hacer_zoom: hace zoom

### Requiere
- permisos de pantalla
- permisos de teclado/ratón
- en algunos casos, cámara o OCR

### Ejemplos
- “mira la pantalla”
- “activa los gestos”
- “haz click allí”
- “escribe hola”
- “pulsa Enter”
